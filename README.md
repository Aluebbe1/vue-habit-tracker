# Daymark — Vue 3 Habit Tracker

A daily habit tracking web application built with Vue 3 and Vite, enhanced using GitHub Copilot and custom repository instructions.

## Live Demo

- **Netlify Live Site:** https://whimsical-monstera-e784bf.netlify.app
- **GitHub Repository:** https://github.com/Aluebbe1/vue-habit-tracker

## Features & Enhancements

- **Daily Progress Tracking:** Displays a real-time completion counter, percentage indicator, and progress bar as habits are checked off.
- **Persistent Storage (`localStorage`):** Automatically saves newly added habits and completion states in the browser across page reloads.
- **Design & Usability Improvements:** Provides clear visual feedback for completed habits and responsive styling for desktop and mobile screens.
- **Custom AI Instructions:** Includes `.github/copilot-instructions.md` to guide GitHub Copilot on Vue 3 Composition API conventions, code clarity, and build verification.

## How to Run Locally
